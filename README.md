# "RPG game"
A WIP game about combining basic elements to create magic spells to defeat enemies. <br /> <br />
This game was originally intended to be a pvp battle royale for a school event, but could not be completed in time for the event. It has now been repurposed to
become an RPG. Due to wanting to avoid a rewrite in the future, we got into premature code cleaning and optimization, which subsequently led to a burnout. 
This project is now on an indefinite hiatus.
